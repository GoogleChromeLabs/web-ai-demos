🧩 Declarative Partial Updates with the Prompt API

A city guide whose five cards are written by five concurrent Prompt API sessions. Each one streams its answer into streamAppendHTMLUnsafe() wrapped in a <template for>, and the browser patches it into the card's <?start>…<?end> range in whatever order the answers arrive.
